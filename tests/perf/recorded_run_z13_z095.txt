=== CAPTURE ROAD (tests/perf/trace_capture_z095.c) ===
An LD_PRELOAD shim forwarding the malloc family to host
glibc (dlsym RTLD_NEXT) and logging every operation as a
32-byte binary record (op, size, ptr, ptr2): allocation,
realloc, free, incl. the memalign family folded to plain
allocations. No stdio and no allocation inside the logging
path (raw write(2) from a static 1 MiB buffer under a
spinlock; a thread-local guard defeats recursion; dlsym's
bootstrap calloc is served from a static arena and never
logged). Record order under concurrency is one valid
interleaving, not per-thread program order; the converter
replays that order single-threaded and this record says so.
Converter (tests/perf/convert_z095.py) drops, each counted,
never silently: zero-size allocations (MimirAlloc's D-013
contract refuses them by design - not replayable events),
allocations above 64 MiB (pattern-write cost would dominate
replay), frees/reallocs of unknown pointers. Replay cap
300,000 ops; histograms cover the FULL capture.

=== DEFECTS FOUND AND FIXED IN SCOPE ===
Two defects in THIS SLICE's own harness, both found by the
first measure run and fixed before the run of record:
(1) probe_z095.c pattern write/check overlapped bytes on
  blocks of size 1-2 (last-byte and middle-byte writes land
  on byte 0), so every replay failed its warmup pattern
  check on traces containing tiny allocations. Fixed by
  guarding each pattern byte by size; proven on a synthetic
  1/2/3-byte trace before re-measurement.
(2) run_z095.sh read probe/bench exit codes through a pipe
  to sed, whose exit status masked failures - the first
  measure run "completed" with an empty replay raw. Fixed
  by capturing output to a file and checking the exit code
  before tagging; a failed run now stops the runner.
No allocator defect was found: variant and baseline
replays agree on checksums exactly, and the standing gate
is green (below).
