- The glibc large_batch leg is DRIFT-REJECT in BOTH runs (11.73% run 1, 9.88% run 2; bound 8%): the leg is BIMODAL - in each run its seven reps split five-and-two between a ~540 ns/op band and a ~660 ns/op band (run 1 in order: 536.45, 540.46, 559.50, 547.70, 680.50, 538.37, 661.75, median 547.70 in the fast band; run 2: 665.21, 661.20, 658.29, 537.70, 654.63, 659.85, 535.49, median 658.29 in the slow band). Two glibc states, not measurement noise: the mimir leg in the same processes is tight (run 2 reps 63.01-67.96, drift 0.23%; run 1 drift 1.93%). Note the drift statistic compares split-half medians, so a bimodal leg trips the 8% bound by construction whichever band its median lands in; the rejection therefore retires the glibc MEDIAN as a precise quantity, not the comparison itself.
- Consequence, stated plainly: the large_batch FACTOR against glibc is indicative in both Z-054 runs (0.116x on run 1 medians, 0.096x on run 2 medians; quoted in the verdict as ~0.10x INDICATIVE). The GRADE does not rest on the rejected median: against glibc fastest single rep in either run (535.49) the mimir median is 0.119x, against its slowest (680.50) it is 0.093x - a WIN of roughly tenfold under every summary choice - and Z-048 drift-clean same-window A/B already graded pool vs glibc 0.13x WIN with the pre-pool base leg as its control (2747.67 ns/op).
