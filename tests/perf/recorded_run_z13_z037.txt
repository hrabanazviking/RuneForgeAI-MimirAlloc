=== DESIGN (what the flag buys) ===
Build-time flag MIMIR_ARENA_CCD (the Makefile never defines
it; the prototype is exercised via the runner's dedicated
objects, Z-034 precedent). TWO arenas, one per CCD, under
the Z-012 constants of record (recorded_run_z012.txt;
Z13_DESIGN_CONSTANTS.md S4): CCD0 = logical CPUs 0-7 +
SMT siblings 16-23; CCD1 = logical 8-15 + siblings 24-31;
cross-CCD shared-line transfer 103 ns vs 32.5 ns intra-CCD
(penalty 3.2x, ARENA_PER_CCD = YES).
- A span's owner arena is fixed at span creation (the
  acquiring thread's arena) and recorded in a side table
  (65536 slots x 16 B = 1 MiB BSS, flag-on builds only;
  at table-full registration fails and span creation
  fails the allocation cleanly, publishing nothing - a
  defined ceiling at 65536 live spans, never a silent
  misroute; Z-034 side-table pattern): the span header
  stays exactly 96 bytes; offsets/capacities unchanged.
- Serving is arena-restricted at BOTH central roads:
  small_alloc_locked and the Z-029 TLS refill road
  (tls_take_one_locked) - i.e. the Wave-4 TLS cache
  machinery shares the partition by construction. The
  caller's arena is read from its CURRENT cpu at each
  central transaction through a flag-guarded L6 query
  (mimir_platform_current_cpu, sched_getcpu; failure
  falls back to arena 0). Blocks already in a thread's
  TLS bins stay valid across a CCD migration.
- The active-span hint is per arena (mimir_arena_active
  [2][20]); span_release_locked performs its active-slot
  writes under the span's OWNER arena (hint saved and
  restored on both exit paths - verified at source).
- Retention (G-007 bound) is counted per arena against
  the bound SPLIT across the arenas (per-arena bound =
  bound / 2, floor; Dossier S4.2 C5: split, not
  duplicated). At the default bound 2: at most 1 empty
  span retained per arena per class, 2 spans = 8192 B
  per class in total - exactly the banked global figure.
  At bound 16: 8 per arena, 64 KiB per class in total.
  An odd bound rounds down (bound 1 -> 0 per arena), so
  the split never exceeds the operator's global bound.
- Every free routes by the block's span, never by the
  freeing thread's arena: cross-CCD and cross-thread
  frees are exactly as correct as on the banked core.
- The one global lock is UNCHANGED. This prototype
  partitions span ownership and selection, not locking:
  the lock road is Z-039's, and Z-038's ladder owns the
  verdict on whether the partition pays. No performance
  claim is made or implied by this slice.
- Refused combinations (compile-time #error, recorded
  scope): MIMIR_DEBUG (debug layout owns its serving
  paths) and MIMIR_OOL_META (the Z-034 trial's serving
  partition is not composed with this one). Composing
  either is future work, not silently untested surface.
- Test surface (INC-E001-07 shape (b), tests/core/
  mimir_arena_z037.h): mimir_arena_snapshot (per-arena
  spans / live objects / selections under the one lock)
  and mimir_arena_current. Internal only; nm -D on the
  shared library stays exactly 4 (no public symbol added;
  the arena objects are never linked into the .so by the
  Makefile).

Accounting note (named, not hidden): span/core live
counts were read at quiescent points - after draining the
calling thread's TLS cache / a central transaction -

recorded in CAMPAIGN_STATE.md as follow-up work; this
prototype neither fixes nor worsens it.
