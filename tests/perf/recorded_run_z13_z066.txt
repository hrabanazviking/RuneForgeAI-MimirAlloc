S2. Mechanism (all in src/core/mimir_core.c/.h)
Descriptor form -- descriptor_lengths_audit_locked(), consulted
at the head of retire_locked, the single choke point every
descriptor release passes through (mimir_core_free,
mimir_realloc transfer retire, retire_any_locked rollback):
walk the live registry with the J-006 step bound, sum
mapping_length over descriptors passing descriptor_is_live,
require walked count == mimir_live_mappings and walked sum ==
mimir_live_bytes -- exactly the byte-sum invariant
mimir_core_metadata_check already proves of every valid tree
(docs/PHASE_10_METADATA_INTEGRITY.md S3 item 6). On mismatch the
retirement is refused BEFORE any state moves: the caller reads
it as an F-06 release failure (block stays LIVE, counters
untouched, nothing unmapped on an untrusted length). The audit
cannot say WHICH descriptor is corrupt, so refusal is
registry-wide while an episode is open (fail-closed, S6); the
first refusal of an episode (a walked sum not seen before)
tallies one detection, later refusals of the same walked sum
tally as collateral, and a passing audit closes the episode.
Span form -- span_length_is_true() added to span_header_is_live
and span_header_is_live_for_free: a span's mapping is always
exactly one system page (span_acquire_locked acquires page_size
and refuses mapping_length != page_size before publication; no
valid code writes a span's mapping_length afterwards). The page
size is cached in a file-scope atomic at first span publication
and the validators hold the header to it, so the consistently
doubled pair now fails validation: the span is bypassed for
allocation and refused for central free, exactly like a
magic-corrupt span.
Diag wiring -- the J-007 channel gains op FREE (3, appended) and
cause METADATA (6, appended); no existing enumerator, name, or
offset changes anywhere. Locked detection sites set a
thread-local label; mimir_core_free consumes it AFTER unlocking
and calls mimir_core_diag_report(OP_FREE, CAUSE_METADATA, 0)
(the channel's own contract: allocation-free, env-gated by
MIMIRALLOC_DIAG=1, closed gate = no output and no emission
counter movement). A Z-066 refusal on the realloc transfer path
reports op=realloc cause=metadata instead of the historical
backing label. Detection tallies are a stats surface, appended
at the END of struct mimir_stats (Z-064 append discipline):
metadata_detections and metadata_collateral_refusals, copied by
mimir_core_stats_snapshot and readable lock-free through
mimir_core_metadata_detections() /
mimir_core_metadata_collateral_refusals() (shape (b), bound
local; nm -D on libmimiralloc.so stays exactly 4, verified).

S6. Scope of the DETECTED claim (verbatim, per red-team review)
INC-J006-02 classes 1-2 DETECTED: descriptor registry sum +
  span mapping_length, single non-compensating corruption on
  a live block only.
INC-J006 remains OPEN.
Owner-scratch: SILENT / NOT DETECTED.
Class-consistency: SILENT / NOT DETECTED.
Compensating multi-descriptor corruption: NOT DETECTED
  (proven as the compensating leg of test-z066: a +1 page /
  -1 page pair whose shrink side also lowers requested_size
  keeps the walked sum equal; without the requested_size
  lowering, descriptor_is_live catches the shrink side alone).
Pooled-descriptor corruption: NOT COVERED (a descriptor
  corrupted while POOLED is off the live registry and outside
  the audit; the walk's pool byte-sum still flags it when a
  checker runs).
Descriptor refusal is registry-wide and fail-closed: while
  one episode is open, valid blocks' retirements also refuse
  (tallied as collateral, one diag line per refused retire).
  It ends the moment the corruption is repaired (the probes
  restore and free cleanly) -- the same non-destructive
  refusal posture as J-006's own detections, widened from
  one block to the registry because a byte sum cannot
  localise. Detection is NOT localisation: the audit proves
  some live descriptor's length accounting is corrupt,
  never which one.
Span/TLS posture: objects already sitting in a thread's TLS
  bin when a span is corrupted are served from the bin
  without re-validation (Z-029's posture for every header
  corruption class); detection fires at the next central
  touch (carve selection, refill, central free). A
  same-thread free of a corrupt span's block bins it; the
  refusal surface for spans is the central (cross-thread)
  free, the carve/refill selection, and the walk.

S7. Cost (same-machine A/B, base = pristine seat c0e19cd objects,
patched = this tree; bench links the core objects directly,
20000 reps x 5 rounds, median ns/op, taskset -c 5, quiet window;
the Z-048 pool serves the large legs, so these are pool-hit
prices, not mmap prices)
  large alloc/free pair (20000 B):
    1 live mapping held:   base 31 ns/op, patched 32 ns/op
    65 live mappings held: base 31 ns/op, patched 166 ns/op
  large realloc transfer (20000 -> 100000, then free):
    1 live mapping held:   base 161 ns/op, patched 161 ns/op
    65 live mappings held: base 170 ns/op, patched 479 ns/op
  small alloc/free pair (32 B): 20 ns/op both, at both holds.
Reading: the descriptor audit costs ~2 ns per live registry
entry per retirement (the transfer leg pays it twice: transfer
retire + final free), immeasurable at desktop live-mapping
counts and linear in them; the span relation and the free-path
label cost nothing measurable on the small path. This is the
honest price of the walk-promotion design, recorded for the
Z-069/Z-070 economics slices: if a future workload holds many
large mappings hot, the O(1) alternatives named by INC-J006-02
itself (a static side record of true lengths, or a checksum --
the latter blocked on the C1.4 reserved-byte duty) are the
named successors. No perf gate is named by the Z-066 roadmap
entry; the standing correctness gate is green.
