=== METHOD ===
The Phase-9 F-series fragmentation legs (I-006; docs/PHASE_9_FRAGMENTATION_AND_RECLAIM.md; definitions in docs/PHASE_9_BUDGET_AND_TELEMETRY_DESIGN.md) ported to this host. Every expectation the old test hardcoded from the 16 KiB-page host (page, capacities, mapping lengths, span counts, F-3) is DERIVED from the measured 4096 B page here. The as-is I-006 run on this host (hidden_files/z055_i006_as_is.log: 41 failures / 120 checks) decomposes into (a) those host-assumption failures and (b) non-quiescence failures: since I-006 the core gained Z-029 TLS free batching, the Z-038 per-class retention bound, and the Z-048 mapping cache, so the old test read counters at non-quiescent points. No allocator defect is evidenced by the as-is log (every pattern check passed, final counters reconciled). Quiescence in the port is established by mimir_core_trim_retained_some(0) before every snapshot: it flushes the TLS bins and drains to core while releasing nothing itself. The fragmented state is built class by class with measured per-class counter deltas (distribution across spans changed since I-006), and F-3 / tails are computed from those measured counts. F-6 is filed two ways: this probe's own Q-MAPPED / Q-RETAINED TRAJ trajectory at every phase, AND the cross-slice leg owed by O-08 / INC-I006-02 - forked RLIMIT_AS-constrained children in I-005's method sampling Q-MAPPED / Q-RETAINED inside the constrained runs. F-5 remains NOT MEASURED: no budget enforcement exists at this base (INC-I006-01, carried from INC-I001-14); reported absent, never approximated.
RAW-FILE NOTE (cosmetic, disclosed): the probe's run_child forks without an fflush(stdout) before fork, so when stdout is redirected to a file each F-6 child's own fflush also flushes the parent buffer it inherited - the sections preceding each child appear duplicated in the raw file (and the summariser, scanning the raw, repeats the F-1(a) headline lines). The duplicated lines are byte-identical copies; no value conflicts, no check is double-counted in the probe's own checks=120 tally (children tally separately: A 9, D 7), and the verdict logic (zero FAIL lines, RESULT: PASS, both children failures=0) is unaffected. The pilot-2-passing source is filed AS IT IS per the campaign transport law; the flush fix is a cosmetic follow-up, not a slice requirement.
