SURFACE (decision D-012; behaviour by analogy under
[UNRESOLVED: U-03] to contracts.md MA-COND-USABLE-01/02,
with the V-05 per-target semantics D-012 defines):
  size_t mimir_usable_size(const void *ptr)
The public name is the namespaced mimir_* shape. A
malloc_usable_size-shaped standard name is NOT declared
and NOT exported by this slice: standard-name
interposition is Wave 10's opt-in business (Z-082), the
same posture as Z-073's aligned entries. The const
parameter records MA-COND-USABLE-01's no-modification
clause in the type.

SEMANTICS (the answer is read from the allocator's own
records, never computed from the request, never a guess):
  - span block (any request the class machinery served,
    1..1024 bytes at publication): exactly the span's
    class size. No per-object requested-size record
    exists under the G-002 span layout (INC-G003-03);
    the class extent is the block's whole usable extent.
  - mapping block (requests above the cutoff, and every
    aligned block above the family floor): exactly the
    descriptor's usable_size (mapping_length -
    usable_offset), revalidated live on the lookup.
  - NULL: 0. A pointer the registries determine is not
    a live block (foreign, interior, already freed --
    central free, this thread's own TLS bin, retired
    descriptor): 0, non-destructively; the argument is
    never dereferenced.
  - realloc shrink never reduces the answer (small:
    class retained; large: only the requested-size
    record drops). A move answers the new block's own
    extent.
  - lock failure at entry: 0 (the F-07 posture carried
    to a query); untriggerable through the public API
    on a healthy host, rests on inspection
    (INC-C005-03).
  - named boundary: a block freed into ANOTHER thread's
    TLS bin is indistinguishable from live (the cache
    holds no cross-thread identity index, Z-028 S9);
    querying a pointer another thread freed is
    use-after-free, UB across the family
    (MA-COND-USABLE-03). Above-page aligned extents are
    per-block record state for the same reason in
    miniature: the offset depends on the mapping base's
    alignment residue (probe: 8192/100 -> 12288,
    16384/100 -> 8192); the test pins invariants there
    and exact values everywhere a closed form exists.
