SURFACE (the Z-073 contract, docs/Z13_ALIGNED_ALLOCATION_
CONTRACT.md, rows AL-073-*):
  void *mimir_aligned_alloc(size_t alignment, size_t size)
  int   mimir_posix_memalign(void **memptr, size_t alignment,
                             size_t size)
Validity is FORM, not magnitude: aligned_alloc valid iff the
alignment is a non-zero power of two; posix_memalign valid iff
additionally a multiple of sizeof(void *) (else EINVAL,
*memptr unchanged; NULL memptr is defined EINVAL, the
contract's deliberate safer divergence from POSIX UB). No
size-multiple rule. Failure of a valid request is NULL /
ENOMEM (*memptr unchanged), never an invalidity; the pointer
entry's only channel is NULL (errno not promised, U-10), the
posix entry's only channel is its return value (errno not
set). Aligned blocks are releasable by mimir_free exactly
once; alignment does NOT survive mimir_realloc (floor only).

ROUTING (over the core's machinery, by measurement):
  - alignment <= 16 (_Alignof(max_align_t) on this host):
    the ordinary dispatch, class machinery included -- every
    pointer this allocator returns already meets the floor
    (Z-017: 0 sub-16 in 163,840 blocks per leg).
  - 16 < alignment <= 4096 (page size): the mapping path at
    any size; its user pointer is page-aligned and a
    power-of-two alignment <= the page divides it. The class
    machinery is deliberately NOT used here: Z-017 measured
    it unable to promise these alignments (64 B class: every
    pointer at ptr mod 64 == 32; 48 B class: 49.41% split).
    PRICE, recorded honestly: such a request pays a whole
    mapping (>= 2 pages), exactly as any request above the
    1024-byte cutoff already does.
  - alignment > 4096: alloc_aligned_locked, the mapping
    construction with usable_offset computed as
    round_up(base + page_size, alignment) - base, inside a
    mapping acquired for the worst-case total
    alignment + page_size + size. Success is GUARANTEED in
    this implementation (stronger than the contract's
    AL-073-06 floor, which permits clean failure beyond the
    page but never a misaligned success).
Every aligned block is a mapping-registry block whose user
pointer is exactly mapping_base + usable_offset, so free and
realloc flow through the untouched mapping courses;
descriptor_is_live admits the computed offset unchanged.
Two E-005-shape audit counters are APPENDED at the L1
boundary (mimir_audit_call_aligned_alloc /
mimir_audit_call_posix_memalign), bound local in the .so;
the export list grows from exactly 4 to exactly 6 as an
explicit contract change (this slice's whole purpose).
