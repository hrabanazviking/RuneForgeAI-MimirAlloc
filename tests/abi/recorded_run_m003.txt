METHOD: per flavour, TWO clean builds. (1) ENUMERATION pass:
extended warning set WITHOUT -Werror, make -k, so every warning
in every translation unit is emitted and captured. (2) GATE pass
(after the in-slice fix): extended set WITH -Werror, clean build;
exit 0 + zero 'warning:' lines = gate passes. Extended set added
on top of each flavour's own flags:
  -Wconversion -Wshadow -Wstrict-prototypes -Wmissing-prototypes
  -Wundef -Wdouble-promotion
(the base -Wall -Wextra -Werror of CFLAGS is retained in the gate
passes; in enumeration passes -Werror is dropped only so the sweep
can see past the first warning). No candidate flag was excluded:
all six are supported by gcc 12.2 and none produced a
false-positive flood (totals below). Sections below keep every
compile command line (cc ...), every warning verbatim with its
source-excerpt lines, and every CHECKS/RESULT summary line;
routine per-check [ok] test output is elided from this record
(full raw logs were captured on the Pi during the run).

FLAVOUR INVENTORY (from Makefile at base, cited in the doc S2):
- production: CFLAGS = -std=c11 -Wall -Wextra -Werror -pthread
  -Iinclude -Isrc -O2 ; targets all/test/lib/static-lib, build/
- debug: DEBUG=1 adds -DMIMIR_DEBUG=1 (BUILD=build-debug);
  DCFLAGS = $(CFLAGS) -DMIMIR_DEBUG=1 for lib-debug, build-debug/
- hardened: HCFLAGS = $(CFLAGS) -O2 -D_FORTIFY_SOURCE=3
  -fstack-protector-strong -fstack-clash-protection -Wformat
  -Wformat-security -Werror=format-security ; HARDLINK relro/now/
  noexecstack ; targets lib-hardened/test-j008, build-hardened/
Extended flags were injected by overriding CFLAGS on the make
command line with the flavour's full base set + extended set;
HCFLAGS/DCFLAGS derive from CFLAGS in the Makefile, so the
hardened and debug library builds inherit the extended set
(visible in the compile lines of Sections C, E, F).
